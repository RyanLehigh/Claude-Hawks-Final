# Project instructions

## Reference material
The `reference/` folder holds project context (assignment docs, notes,
papers, data descriptions). It is committed to the repo.

At the start of every session, before doing any work:
1. List everything in `reference/` (including subfolders).
2. Read each file (text, markdown, PDF, spreadsheets, images) so its content
   informs your answers — treat it like the knowledge base of a Claude project.
3. If a file is too large, skim it and read the relevant parts when needed.
